# Kernel source placeholder for Redmi Y3 (`onc`)

This directory is meant to contain the Qualcomm MSM8953 kernel source used by the Redmi Y3.

Recommended upstream reference:
- https://github.com/onclite/android_kernel_xiaomi_onc
- https://github.com/LineageOS/android_kernel_qcom_msm8953

This project will eventually carry device-specific kernels and fixes for:
- display
- touch
- camera
- audio
- thermal regulation
- memory tuning for 3GB RAM
- boot and recovery compatibility
