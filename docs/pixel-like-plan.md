# Pixel-like design plan

The ROM target is a lightweight Pixel-inspired experience rather than a redistribution of Google proprietary applications.

Planned open-source changes:

- Material You-compatible system color configuration
- restrained animation scales for Snapdragon 632
- lightweight default launcher configuration
- Pixel-like default wallpaper and icon arrangement where licensing permits
- minimal preinstalled packages
- ZRAM/LMKD tuning only after device measurements

Google Pixel proprietary apps, branding, wallpapers, and binaries must not be copied into this repository without appropriate rights. GApps should remain an optional, separately obtained package.
